Maskot Nemo — Eksplorasi Dark Mode

Perbandingan langsung tanpa lingkaran putih tebal (solid badge) yang menyilaukan.

Kondisi Sekarang
Bulatan Putih Solid
Lingkaran putih pekat 100%. Rambut kontras, tapi terasa seperti stiker bulat yang terlalu silau di dark mode.
// Compose saat ini Modifier.background(Color.White, CircleShape) .padding(size * 0.08f)
Rekomendasi #1
1. Soft Radial Backlight
Glow halus tanpa garis batas bulat. Tetap natural melayang di background, rambut hitam kontras tegas.
// Compose (Brush.radialGradient) Modifier.drawBehind { drawCircle( Brush.radialGradient( listOf(Color.White.copy(0.18f), Color.Transparent), radius = size.minDimension / 1.5f ) ) }
Opsi #2
2. Dark Surface Badge
Container bulat senada warna surface dark mode (#141414) + border 1px tipis + inner glow halus.
// Compose Modifier.background(NemoNight.surface, CircleShape) .border(1.dp, NemoNight.line, CircleShape)
Opsi #3
3. Silhouette Rim Glow
Drop-shadow putih tipis yang presisi mengikuti lekukan rambut dan dagu. Benar-benar bebas container.
// CSS / GraphicsLayer shadow filter: drop-shadow(0 0 2px rgba(255,255,255,0.7)) drop-shadow(0 0 8px rgba(255,255,255,0.25));
Opsi #4
4. Inverted Lineart Asset
Garis dan rambut putih di atas badan gelap (memakai aset bawaan nemo_mascot_white). Kontras murni tanpa efek.
// Asset switch saat Dark Theme val res = if (isDark) R.drawable.nemo_mascot_white else R.drawable.mascot_neutral
Simulasi di Dalam Kartu Insight / Task Header (Dark Mode Nemo)

"Kamu sudah fokus 2 jam tanpa distraksi hari ini."

Dengan Opsi 1 (Soft Radial Backlight), siluet rambut hitam Nemo tetap kontras terhadap background kartu (#141414) dan background layar (#0A0A0A) secara harmonis, tanpa ada lingkaran putih kaku seperti stiker.

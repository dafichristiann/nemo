# AI Insight (Gemini) — Design Spec

> **Status:** Implemented · **Tanggal:** 2026-10-08
> **Sumber:** `01-prd.md` v0.3 §10.8, §13.1 (FR-AI1..AI8, OQ-AI)
> **Terkait:** `09-privacy-and-security.md`, `15-post-mvp-roadmap.md` (P6-8 dipromosikan)

## Tujuan

Mengaktifkan AI Personal Insight **sungguhan** memakai **Gemini REST API**, tetap:
opt-in (default OFF), hanya mengirim **agregat**, dan selalu punya **fallback rule-based**.

## Arsitektur

```
GenerateDailyReflectionUseCase
   ├─ aiEnabled? ──► AiInsightSource (GeminiInsightSource) ──► InsightDraft (source = AI)
   │                        └─ gagal/offline/no-key → null
   └─ fallback ─────► RuleBasedInsightSource ───────────────► InsightDraft (source = RULE_BASED)
                                    │
                            BuildInsightPayloadUseCase (agregat saja)
```

- **`AiInsightSource`** — kontrak lama, tidak berubah (domain tetap stabil).
- **`GeminiInsightSource`** — implementasi baru: `HttpURLConnection` + `org.json` (tanpa dependency baru).
- **DI** — `InsightModule` bind `GeminiInsightSource` (self-degrading: key kosong → null).
- **`NoOpAiInsightSource`** — dipertahankan sebagai test double / referensi "tanpa key".

## Kontrak fail-soft (FR-AI4, FR-AI8)

`GeminiInsightSource.generate()` **tidak pernah throw**. Return `null` bila:
- key kosong (short-circuit, tanpa network),
- payload gagal `passesPrivacyAudit`,
- HTTP non-2xx (429/403/404/5xx),
- JSON envelope tidak valid / summary blank / schema tidak lolos `InsightSchemaValidator`.

Model dicoba berurutan (`gemini-flash-lite-latest`, `gemini-flash-latest`) supaya model yang
di-retire/overload tidak memaksa fallback.

## Privasi (PRD §13.1)

- Hanya `InsightPayload` (counts/ms agregat) yang dikirim; **tidak ada** raw session,
  judul task, timestamp per-sesi, atau identitas.
- Egress **nol** saat AI OFF (default).
- `INTERNET` + `ACCESS_NETWORK_STATE` di manifest (dipakai hanya jalur AI).

## Konfigurasi

Key diresolusi saat build (yang pertama tidak kosong menang):

1. **Env var** `GEMINI_API_KEY` — paling aman (CI/rilis, tidak pernah jadi file).
2. **Gradle property** `GEMINI_API_KEY` (mis. `~/.gradle/gradle.properties`, di luar repo).
3. **`local.properties`** (git-ignored, machine-specific) — praktis untuk dev lokal:

```properties
GEMINI_API_KEY=<your-key-from-google-ai-studio>
```

→ `BuildConfig.GEMINI_API_KEY`. Bila kosong → perilaku identik dengan no-AI (offline).
Ganti key = edit salah satu sumber + **rebuild** (key disuntik saat build, bukan runtime).

## Verifikasi (device TECNO CN7c, Android 16)

| Kondisi | `insight.source` | Bukti |
|---|---|---|
| AI ON + key | **AI** | "You successfully completed all 3 planned tasks today…" |
| AI OFF | **RULE_BASED** | "You completed all 3 of today's tasks." |
| AI ON tanpa key (unit) | RULE_BASED | `GeminiInsightSourceTest` |

- Unit test: `GeminiInsightSourceTest` (no-key & audit-fail → null, no throw).
- UI: label sumber berganti "Generated by Anchor AI (aggregated data only)" vs
  "Generated locally on your device".
- Quality gate: lint 0 error, 116 unit test PASS.
